📊 Live Stock Monitor

A Streamlit web app that displays live stock prices with automatic refresh, powered by the Finnhub API
.

🚀 Features

Enter multiple stock tickers (e.g. AAPL, MSFT, TSLA)

Auto-refresh at user-defined intervals

Percentage change since last close

Interactive table and line chart

Manual refresh button

🛠️ Tech Stack

Python 3.9+

Streamlit
 – Web UI

Pandas
 – Data handling

Requests
 – API calls

Finnhub API
 – Stock data


Install dependencies

pip install -r requirements.txt


Configure API key

Get a free API key from Finnhub
.

Create a .env file in the project root:

FINNHUB_TOKEN=your_api_key_here
